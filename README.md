# TAPAK LAMPUNG
Jelajahi Ceritanya, Kenali Budayanya. Flutter + Firebase (Authentication, Firestore, FCM). Tanpa Firebase Storage.
Simulasi pengelolaan oleh admin; bukan aplikasi resmi instansi mana pun.

- Beranda modern dengan slot foto budaya asli (docs/SUMBER_FOTO.md).
- Game edukasi (peta, cerita, tantangan, kuis) tetap bergaya ilustrasi dan animasi.
- Rencana Kunjungan, Daftar Belajar, Pengingat Belajar, Jurnal Budaya (foto Base64 di Firestore).
- Notifikasi lokal terjadwal (pengingat) dan FCM push (terpisah). Lihat docs/ANDROID_MANIFEST.md.
- Panduan uji: docs/PANDUAN_UJI_UTS.md.
