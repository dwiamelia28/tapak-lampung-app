# Foto Asli Budaya Lampung

Aplikasi TIDAK menyertakan foto bawaan dan tidak memakai gambar pengganti.
Sebelum foto dipasang, beranda menampilkan placeholder "Foto belum dipasang".

## Nama file (taruh di `assets/photos/`, format JPG)
| File | Isi yang benar |
|---|---|
| `nuwo_sesat.jpg` | Rumah adat Nuwo Sesat (Lampung) |
| `kain_tapis.jpg` | Kain Tapis Lampung |
| `siger.jpg` | Siger / busana adat Lampung |
| `tari_lampung.jpg` | Tari tradisional Lampung |
| `gamolan.jpg` | Gamolan (alat musik bilah bambu Lampung) |
| `kuliner_lampung.jpg` | Kuliner khas Lampung (mis. seruit, engkak) |

## Aturan
1. Pastikan objek benar-benar dari Lampung. Baca keterangan foto (judul, deskripsi, lokasi); jangan memakai
   foto budaya daerah lain yang kebetulan mirip.
2. Gunakan foto dengan lisensi yang jelas, atau foto buatan sendiri.
3. Catat atribusi: isi `credit` di `lib/core/constants/photo_assets.dart` (fotografer dan lisensi),
   contoh `'Nama Fotografer / Wikimedia Commons (CC BY-SA 4.0)'`. Kredit tampil di bawah judul foto.
4. Lisensi CC BY / CC BY-SA mewajibkan atribusi. Hindari foto tanpa lisensi yang jelas.
5. Ukuran file disarankan 1200 px di sisi terpanjang dan di bawah 400 KB agar aplikasi ringan.
